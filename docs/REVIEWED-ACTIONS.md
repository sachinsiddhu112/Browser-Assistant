# Reviewed actions in v0.5

- **Open a link:** The local or cloud model can propose an eligible visible link by index. The panel shows the exact destination and waits for **Open this link**. URLs come from the browser, never the model. Only ordinary visible same-origin HTTPS links without query strings or fragments are supported. Known sensitive paths and download links are excluded. This never simulates a click.
- **Fill approved fields:** Local mode drafts values as before, then waits for **Fill these fields**. The panel shows every proposed value. Only visible empty text-style fields bound to the original page and element can be filled. Password, OTP, payment-like, disabled and file controls are excluded. Nothing is overwritten. A page may respond immediately to an input event; review the destination and values first. If the site changes during filling, check the page for any entries already made before retrying.
- **Manual handoff:** Upload documents and click Submit yourself on the website. The extension does not bypass CAPTCHA, read the file system, upload files, or submit forms. Login and other sensitive interactions remain with the user.
- Approved actions expire and revalidate the active document. Opening a link ends the current action; run another task on the new page. No arbitrary cross-site or fully autonomous workflow is implemented.
- Cloud mode can propose links using labels, not URLs. It does not draft or fill fields and never receives form-field labels or values read from controls. When Cloud mode is enabled, use public pages and non-confidential goals only. Use the v0.5 backend and extension together; the v0.4 API will reject new link labels.
