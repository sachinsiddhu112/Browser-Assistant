# Browser Assistant

Voice and text controlled browser assistant. Initial development foundation; not production ready.

## Setup
Requires Node.js 22 and pnpm 10. Run `corepack enable`, `pnpm install`, then `pnpm dev:extension`. Load the generated `apps/extension/.output/chrome-mv3` directory using Chrome's Load unpacked option. Run `pnpm dev:backend` for the local API.

No credentials should be committed. See docs/PROGRESS.md for status.
